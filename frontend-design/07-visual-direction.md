# 07. Visual Direction

> Directional only — Stage 1 does not finalize visual implementation. This exists so Stage 2 (Design Director) has a starting brief, not a generic default.

## What the market currently looks like (for awareness, NOT for copying)
- **Tanu / Pai by Lee:** generic Shopify/e-commerce template feel — functional but visually undifferentiated, heavy reliance on sale-badge red and default cart UI.
- **Thambulaaa:** warm, gift-forward hero imagery with motivational taglines; fairly conventional multi-level e-commerce header.
- **Wedtree:** the most polished — festival-driven hero banners, mega-menu, trust badges, national e-commerce look. Feels like a large-scale gifting retailer, not a small local shop.

**None of these should be copied** — colors, layout structure, typography, or component style. They are documented here purely so Stage 2 can consciously avoid producing "a 5th version of the same gifting-site template."

## Opportunity / Differentiation Space
Every reference site reads as a fairly generic e-commerce catalogue (cart-driven, badge-heavy, mega-menu navigation). Gifties For You's CONFIRMED scope is explicitly the opposite: a **simple, WhatsApp-first, no-cart catalogue** — this is a real structural difference, not just a visual one, and should be allowed to produce a genuinely different feel: warmer, more personal, more "small shop you can actually message," less "national e-commerce operation." This is INFERRED as an opportunity, not yet validated with the client — flag in Stage 2 kickoff.

## Product Personality (draft — confirm with client before Stage 2)
- **Warm** — gifting is an emotional/social category, not utilitarian
- **Personal/approachable** — small shop, WhatsApp-first, human-scale (vs. Wedtree's large-retailer feel)
- **Trustworthy** — needs to compensate for having no cart/reviews infrastructure yet, so clarity and honesty in presentation matter more
- **Occasion-aware** — the site should feel tied to real celebrations (weddings, birthdays, festivals), not abstract product-grid retail

These are proposed based on the market gap identified above, not confirmed by the client. Should be validated before Stage 2 visual work begins.

## Visual Direction To Avoid By Default
- Generic Shopify-template look (Tanu, Pai by Lee's default feel)
- Cold, corporate, "national retailer" polish (Wedtree's scale-driven aesthetic doesn't fit a small local shop)
- Purple/blue SaaS gradients, glassmorphism, generic AI-default styling — none of these fit a gifting business regardless of market
- Badge-heavy discount styling (red "SALE" badges everywhere) unless the client actually runs promotions this way — UNKNOWN

## Surface / Shape / Contrast / Spacing
Not finalized in Stage 1 — these are Stage 2 (Design Director) decisions once product personality is confirmed with the client. What Stage 1 does establish: the site is content-light (few screens, no dense data), so it should lean toward a **calm, editorial, photo-forward** treatment rather than a dense e-commerce grid — INFERRED from the small/simple scope, to be validated.
